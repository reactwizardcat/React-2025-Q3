# Genshin Impact Characters

![Genshin Impact Logo](/public/genshin.jpeg)

A web application for searching and exploring Genshin Impact characters with detailed information.

## Features

- 🔍 Search for a character by the presence of a character in the name.
- 📊 Detailed character stats at different levels
- 🛠️ Recommended builds and artifacts
- ⚔️ Team composition suggestions
- 🌟 Wish simulator (future implementation)
- 📱 Fully responsive design

## Technologies Used

- React 19
- TypeScript
- Tailwind CSS
- Vite
- Genshin Impact API (own implementation written in golang)

## Project Setup

### Prerequisites

- Node.js v18+
- npm v9+

### Installation

```bash
git clone https://github.com/reactwizardcat/React-2025-Q3.git
cd React-2025-Q3
npm install
```
